# Нефункциональный чек-лист (Yougile)

Включает 3 вида тестирования: UI/UX, кросс-браузерность, доступность. Нагрузочное тестирование не проводится (боевой сайт).

## UI/UX
- [ ] 1. Интерфейс корректно отображается в разрешении 1920×1080, без горизонтальной прокрутки
- [ ] 2. Названия элементов и подписи полей понятны и не обрезаются
- [ ] 3. Сообщения об ошибках валидации отображаются рядом с полем и понятны пользователю
- [ ] 4. Интерактивные элементы (кнопки, ссылки, карточки) имеют состояние при наведении курсора
- [ ] 5. Навигация по разделам приложения интуитивна (дашборд → проект → доска → задача)

## Кросс-браузерность
- [ ] 6. Ключевые сценарии (вход, создание проекта, создание задачи) работают в Microsoft Edge
- [ ] 7. Ключевые сценарии работают в Google Chrome
- [ ] 8. Ключевые сценарии работают в Mozilla Firefox
- [ ] 9. Вёрстка не «плывёт» при изменении размера окна браузера (адаптивность базовых макетов)

## Доступность
- [ ] 10. По интерфейсу можно перемещаться с клавиатуры (Tab, Enter, Escape)
- [ ] 11. Поля ввода имеют текстовые подписи (label)
- [ ] 12. Кнопки и ссылки имеют осмысленные названия для программ чтения с экрана
- [ ] 13. Контраст текста относительно фона достаточен для чтения

Итого: 13 пунктов (UI/UX — 5, кросс-браузерность — 4, доступность — 4).
